## Пункт 5.1. Группировка через .groupby() и метод агрегации .agg(). Построение плоских Pivot-матриц (Conditional Pivot Aggregation на Python).

Пересобираем инструмент с нуля, объединяя логику `GROUP BY` с возможностями RAM для создания плоских аналитических матриц.

---

### АНАТОМИЯ ИНСТРУМЕНТА: АЛГОРИТМ SPLIT-APPLY-COMBINE

Метод `.groupby()` в Pandas использует трехфазный конвейер, работающий с векторов NumPy:
1.  **Split (Разделение):** Pandas сканирует ключи и создает изолированные контейнеры в памяти (`DataFrameGroupBy`).
2.  **Apply (Применение):** К контейнерам применяются функции (`sum`, `mean`, `count`).
3.  **Combine (Объединение):** Результаты собираются в единую плоскую таблицу.

#### Инженерный стандарт: Метод `.agg()`
Используйте `.agg()` для расчета разных метрик за один проход:
```python
summary_df = df.groupby("category", as_index=False).agg(
    total_volume=("quantity_fact", "sum"),
    average_price=("price_per_unit", "mean"),
    orders_count=("log_id", "count")
)
```
*Флаг `as_index=False` сохраняет ключи группировки как обычные колонки (плоский вид).*

---

### ЗЕРКАЛО КЕЙСА №33: CONDITIONAL PIVOT AGGREGATION НА PYTHON

Для реализации условного сумматора (аналог SQL `SUM(CASE WHEN...)`) используем комбинацию `np.where` и `.groupby().agg()`.

```python
import numpy as np
# 1. Создаем условные колонки
df["cost_it"] = np.where(df["category"] == "it", df["quantity_fact"] * df["price_per_unit"], 0)
df["cost_auto"] = np.where(df["category"] == "auto", df["quantity_fact"] * df["price_per_unit"], 0)

# 2. Агрегируем по пользователям
pivot_matrix = df.groupby("user_id", as_index=False).agg(
    total_cost_it=("cost_it", "sum"),
    total_cost_auto=("cost_auto", "sum")
)
```

---

### ДЕФЕКТЫ И КАПКАНЫ (ОТК-КОНТРОЛЬ)

1.  **Проблемы с регистром/пробелами:** Разные написания ('IT' и 'it ') создают разные группы. Необходима предварительная очистка (`.str.strip().str.lower()`).
2.  **Исчезновение `NaN`:** По умолчанию `.groupby()` игнорирует строки, где ключ — `NaN`. Используйте `dropna=False` для включения пустых значений в расчет:
    ```python
    df.groupby("category", as_index=False, dropna=False).agg(...)
    ```

---

### КРАТКИЙ ИТОГ
*   **Conditional Pivot Aggregation** = `np.where()` + `.groupby().agg()`.
*   **`dropna=False`** — защита от потери данных в пустых ключах.
