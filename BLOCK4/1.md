ЛОК: Работа с временными рядами (DateTime)В реальных задачах аналитика даты почти всегда загружаются как обычный текст (object). Чтобы проводить временной анализ, их необходимо приводить к типу данных datetime64.1. Преобразование в DateTime: pd.to_datetime()Основной инструмент для изменения типа данных.python# Базовая конвертация колонки
df['date'] = pd.to_datetime(df['date'])

# Обработка "грязных" данных (ошибки превратятся в NaT — Not a Time)
df['date'] = pd.to_datetime(df['date'], errors='coerce')

# Явное указание формата (ускоряет работу и исключает ошибки интерпретации)
df['date'] = pd.to_datetime(df['date'], format='%Y-%m-%d %H:%M:%S')
Используйте код с осторожностью.📊 Шпаргалка по символам форматирования (Format):%Y — четырехзначный год (2026)%m — месяц числом (01-12)%d — день месяца (01-31)%H — час в 24-часовом формате (00-23)%M — минуты (00-59)2. Извлечение компонентов даты: Аксессор .dtПосле конвертации открывается доступ к атрибуту .dt. Он позволяет разбирать дату на составляющие без циклов (векторизованно).python# Извлечение года, месяца и дня
df['year'] = df['date'].dt.year
df['month'] = df['date'].dt.month
df['day'] = df['date'].dt.day

# Извлечение дня недели (0 — Понедельник, 6 — Воскресенье)
df['weekday'] = df['date'].dt.weekday

# Название дня недели или месяца текстом
df['month_name'] = df['date'].dt.month_name()
df['day_name'] = df['date'].dt.day_name()
Используйте код с осторожностью.3. Фильтрация по датамС типом datetime64 работают стандартные операторы сравнения и строки-даты в любом понятном формате.python# Фильтр по конкретному году
df_2024 = df[df['date'].dt.year == 2024]

# Фильтр по диапазону дат (логическое И)
filtered_df = df[(df['date'] >= '2025-01-01') & (df['date'] <= '2025-03-31')]

# Использование метода .between()
filtered_df = df[df['date'].between('2025-01-01', '2025-03-31')]
Используйте код с осторожностью.4. Временная математика: pd.TimedeltaПозволяет вычислять разницу во времени или сдвигать даты на определенный интервал.python# Вычисление разницы между двумя датами (получаем тип timedelta)
df['delivery_time'] = df['delivered_date'] - df['order_date']

# Извлечение чистой разницы в днях (перевод в числовой тип)
df['days_to_delivery'] = df['delivery_time'].dt.days

# Прибавление фиксированного времени к дате
df['deadline'] = df['order_date'] + pd.Timedelta(days=7)
df['reminder_time'] = df['order_date'] - pd.Timedelta(hours=2)
Используйте код с осторожностью.⚠️ Ловушка на собеседовании (Важно!)Вопрос лида: «Как сгруппировать данные по месяцам, чтобы посчитать выручку?»Ошибочный ответ: df.groupby(df['date'].dt.month)['revenue'].sum()В чем баг: Если в датасете есть данные за 2024 и 2025 года, метод сложит январи 2024 и 2025 годов в одну корзину.Правильный ответ: Группировать нужно либо по связке Год-Месяц, либо через приведение даты к началу месяца (.dt.to_period('M')):python# Правильный вариант №1: группировка по двум признакам
df.groupby([df['date'].dt.year, df['date'].dt.month])['revenue'].sum()

# Правильный вариант №2: округление даты до месяца (2024-01, 2024-02...)
df['month_period'] = df['date'].dt.to_period('M')
df.groupby('month_period')['revenue'].sum()
